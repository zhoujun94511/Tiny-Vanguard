# 玩法、节奏与打击感深化设计方案

本方案针对 **Tiny Vanguard** 的「荒野生存」与「通道守卫」两大原创核心模式进行系统性玩法、操作手感与节奏打磨：

## 1. 痛点识别与系统设计

| 维度 | 改进前现状 | 优化实现 |
|---|---|---|
| **通道守卫目标清晰度** | 左右两扇光门无文字标记，无法直观判断奖励差异 | 光门上方新增 3D 动态看板，实时显示奖励（如 `+1 弹丸` / `Lv.2 充能` / `⚠ 污染净化`）与进度 |
| **通道守卫索敌、防隧穿与底板** | 仅按直线距离索敌，高速弹丸打门可能跨步穿透，桥尾近景偶有水面透底 | 索敌优先最逼近防线的敌人并兼顾贴脸自卫；光栅改用线段扫掠碰撞；桥尾 `maxZ` 延展至 `26` 并加装连续深色底板 |
| **动作操作上限与技能轮盘** | 仅能匀速平移，技能并排挤压小屏空间 | 右下角重构为**极坐标弧形技能轮盘**，集成 **冲刺（`Space`）**、**圣盾（`E`）** 与 **星爆（`Q`）** 三大主动技 |
| **荒野生存节奏与补给爽感** | 前期升级过快（每 5~7 秒弹窗打断）；补给仅回血+局部震荡 | 校准 `xpCurve` 为 `{ base: 68, growth: 1.17, exponent: 1.02 }`；拾取空投触发**全图经验磁吸潮汐**与清场脉冲 |
| **战斗打击感与听觉舒适度** | 缺乏飘字微震，早期 BGM 节拍过快易听觉疲劳 | 新增零分配 2D Canvas 飘字与微震相机；音频降速至 `82–114 BPM` 温润编曲并收紧高频音效节流 |

## 2. 双模式差异化节奏规划

### 模式 A：荒野生存（Roguelite 生存割草）
- **破冰期（0～1 分钟）**：约 12~16 秒触发首次三选一，首分钟维持在 Lv.4～Lv.5，专注走位与基础战技熟悉。
- **走位破局（1～3 分钟）**：引入冲锋怪、远程法师与阵型波，利用 `Space` 冲刺与 `E` 圣盾化解合围。
- **狂潮高潮与首领（3～6 分钟）**：精英护卫、限时全息空投与 25/60/120 连杀狂热接力，最终迎战终局泰坦首领。

### 模式 B：通道守卫（防线策略守卫）
- **无弹窗流畅节奏**：取消暂停式弹窗；升级与击杀直接叠加属性、战技与遗物。
- **双路策略博弈**：每 18 秒刷出左路击破门与右路充能/污染净化门，在「清线保血」与「射击充能翻倍收益」之间实时抉择。
