# Tiny Vanguard 玩法与数值设计

## 1. 双模式关卡体系与无尽深渊

- **荒野生存（`meadow-arena` 翠风草甸 / `ember-cauldron` 熔岩峡谷 / `shadow-ruins` 幽影废墟 / `astral-throne` 星渊王座）**：
  - 采用 42° 3D 动作斜视角，4 阶段递进敌潮（初入蓄势 → 敌潮走位 → 精英护卫与阵型波 → 狂潮割草 → 终局泰坦首领战）。
  - 经验曲线采用 `{ base: 68, growth: 1.17, exponent: 1.02 }`，开局约 12~16 秒（7~8 杀）完成首次三选一觉醒，平滑覆盖 4.5~6 分钟至 Boss 战的完整成长周期。
  - 默认上限 **4 个自动战技槽位**，定时生成限时全息空投补给舱与可直穿遗物；第 4 关首领击杀后可进入**无尽深渊**并支持每波首领后主动撤离结算。
- **通道守卫（`bridge-defense` 木桥防线 / `frost-bridge` 霜雪栈桥 / `iron-viaduct` 钢铁高架 / `abyss-span` 深渊断桥）**：
  - 锁定纵深防线视角与红白警戒线，采用**无弹窗流畅节奏**（升级、击杀与光栅收益直接叠加到角色属性与战技）。
  - 每 18 秒生成双路无框全息激光光栅：双路均可通过射击升阶（`Lv.1 → Lv.3`，满阶锁定 `100%`）或净化红框污染门跃升 `Lv.2` 双倍收益，最终由主角走位穿过实现严格二选一互斥领奖；第 4 关首领击杀后同样支持**无尽深渊**。

## 3. 暗黑式三阶段局外养成闭环（军备库）

- **Stage 1（核心养成闭环）**：
  - **5 级圣物品质**：20 件圣物按 `common`（白）→ `uncommon`（绿）→ `rare`（蓝）→ `epic`（紫）→ `legendary`（橙）分级展示。
  - **英雄解锁与 1★→5★ 升星**：`chibi-knight` 初始可用，`storm-ranger` / `iron-bastion` 通过局后英雄碎片或星耀解锁并升星；老胜利存档（`victories > 0`）自动兼容解锁。
  - **渐进关卡解锁与 2 槽本命圣物**：同模式需通关第 N-1 关解锁第 N 关（保留 `?debug=1` / `F9` 全开通道）；点亮图鉴后的圣物可装备到本命配装槽（默认 1 槽，40⭐ 解锁第 2 槽）带入开局。
  - **8 项军备天赋**：新增「命运骰子」（开局重随 +1/级，上限 3 级）与「弑王锋芒」（对精英/首领伤害 +8%/级，上限 5 级）。
- **Stage 2（圣物精炼与宝石工坊）**：
  - **圣物精炼（+1 → +5）**：消耗星耀提升圣物基础属性（每级 `+15%`）。
  - **圣物开孔与宝石镶嵌**：花费 15⭐ 为圣物开孔，通关与无尽首领掉落 4 种宝石（红宝石/翡翠/蓝宝石/黄玉，Lv.1~Lv.3），支持 **3 合 1 升阶**与**无损镶嵌/卸下**。
- **Stage 3（附魔洗练与圣物共鸣）**：
  - **附魔洗练**：花费 12⭐ 洗练 6 种实战附魔词条；双槽同时携带 2 件稀有及以上圣物时激活「圣物共鸣」（全伤害 +8%、最大生命 +20）。
  - **无尽巅峰超限突破（Limit Break）**：双模式进入无尽后，每击杀 1 只无尽首领永久在本局叠加 `+14% 伤害 / +10% 暴伤 / +15 HP / +4% 攻速`；荒野模式常规升级拿满后，「战地急救」自动转为无限可选的「深渊巅峰突破」（`+6% 伤害 / +10 HP / 回血 35%`）；同时无尽怪物每阶（45 秒）同步缩放血量（`+28%`）与温和伤害（`+4%`，上限 `3x`）。
  - **战前总览与结算反馈**：选关界面实时计算并展示 `PreRunPreview` 战前出征属性，结算弹窗为首次点亮的圣物标注 `NEW` 角标。

## 2. 五大自动战技与三大主动技轮盘

- **五大自动战技（Auto Skills）**：
  1. **星辉连弹 (`star-blaster`)**：自动索敌发射定向星光弹丸（桥守模式兼顾近身威胁与光栅瞄准）；共鸣进化「分裂星弹」。
  2. **守护星环 (`orbit-shields`)**：绕身旋转的近身护卫星盾；共鸣进化「呼吸星轨」。
  3. **寒霜震荡波 (`frost-nova`)**：周期性释放范围冰霜冲击波并减速；共鸣进化「双重余震」。
  4. **雷鸣链刃 (`thunder-arc`)**：基于 `SpatialGrid` 密度查询专劈最密集怪堆质心的高压电弧；共鸣进化「超载感电」。
  5. **星轨重狙 (`rail-sniper`)**：专点首领 > 精英 > 重盾 > 最高血量目标的贯穿激光束；共鸣进化「破盾穿甲弹」。
- **右下角极坐标弧形轮盘（三大主动技）**：
  - **`Space` / 冲刺**：战术位移 + 短瞬无敌帧 + 离子残影。
  - **`E` / 圣盾 (`Aegis Guard`)**：8 秒基础冷却，提供最大生命值 22%（至少 20 点）护盾、`0.3s` 无敌与 `4.8m` 冰霜减速击退冲击波。
  - **`Q` / 星爆 (`Starfall Fury`)**：击杀充能至 100% 释放天降星陨光柱与全屏清场冲击。
